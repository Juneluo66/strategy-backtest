# Dual Momentum ETF

US ETF dual-momentum research package: month-end signals, next-open execution,
10-month SMA trend filter, optional vol-adjusted scores, asset-class constraints,
and 5% relative hysteresis.

## Variants

| Name | Description |
|------|-------------|
| `baseline_6` | SPY/QQQ/IWM/VEA/GLD + SGOV; raw score; Top-2; hysteresis |
| `own_v1` | Expanded pool; score/σ60D; max one per category; Top-2 |
| `A_vol_adj` | Baseline pool + vol adjustment only |
| `B_regime_size` | SPY regime controls Top-2 vs Top-1 vs full cash |
| `C_trend_consistency` | Require R3M, R6M, R12M all positive |
| `D_category_only` | Category constraint without vol adjustment |

Cash sleeve is **SGOV**, with **BIL** as proxy before SGOV history exists.

## Quick start

```bash
cd /home/ec2-user/strategy-backtest/dual_momentum_etf
python3 -m pip install -e '.[dev]'
dual-momentum-etf fetch
dual-momentum-etf audit
dual-momentum-etf run --variants baseline_6,own_v1
dual-momentum-etf ablation
dual-momentum-etf attribution   # A/C/D/hyst interaction vs SPY/QQQ/60-40/MA/EW
dual-momentum-etf confirm       # Final D+C confirmation (frozen; no combo search)
dual-momentum-etf sleeve        # D+C as pre-declared SPY defensive sleeve (no weight search)
dual-momentum-etf final-audit   # PIT outer blend + simple defenses; seeds IBKR paper books
dual-momentum-etf paper         # Re-run IBKR-constraint paper books only
dual-momentum-etf cost-stress
dual-momentum-etf report
```

Interaction attribution writes `reports/interaction_attribution.md`.
D+C confirmation writes `reports/dc_confirmation.md`.
Relative-to-SPY opportunity-cost audit (metrics A/B/C + chart) is regenerated by `dual-momentum-etf confirm`
into `reports/relative_nav_drawdown.png` and the Relative-to-SPY section of `dc_confirmation.md`.
Sleeve evaluation writes `reports/dc_sleeve_evaluation.md`.
Final audit writes `reports/dc_sleeve_final_audit.md` and `reports/PROJECT_STATUS.md`.
Paper books: `configs/paper_trading.yaml` → run artifacts under `reports/runs/*_paper_*`.

**Frozen portfolio decision:** default paper candidate = **80% SPY + 20% D+C**;
60/40 SPY/D+C is conservative shadow only (no further weight search).
D+C 3/6/12 + category rules are frozen.

## Rules (frozen)

- Score = 0.6·R5M + 0.4·R12M on month-end closes
- Risk assets must close above their 10-month SMA
- Top 2 equal weight; residual cash
- Replace only if challenger score > incumbent × 1.05
- No leverage, no shorting
- Default one-way cost 5 bp
